# Redacción pendiente — catálogo de arranque

Cada producto lleva dos bloques:

- **CERRADO** = textual de los documentos del cliente. No se toca.
- **FALTA** = el documento no lo define. Va una **PROPUESTA** mía, marcada como tal, para que se apruebe, se edite o se descarte.

Regla: **ninguna propuesta se publica sin visto bueno.** Son afirmaciones sobre qué entrega el producto.

Los cuatro datos que toda ficha debe mostrar siempre (requisito del PDF-2):
**Qué es · Qué aprenderás · Para quién es · Cuánto tiempo necesitas**
